Arrange Home Screen apps, folders, widgets and the App Library from your Mac.

- Layout support for iOS 16, 17, 18, 26 and 27; iOS 16 uses sequential icon placement.
- Per-device drafts and backups, readback comparison, local editor, CLI and MCP server.
- Apple silicon Mac, macOS 14 or later; ad-hoc signed app.

Install: open the DMG and drag iOS Home Screen Organizer into Applications, or extract the ZIP. Open System Settings → Privacy & Security → Open Anyway when macOS requests approval.

Download both archives and SHA256SUMS.txt into the same directory, then run `shasum -a 256 --check SHA256SUMS.txt`.
